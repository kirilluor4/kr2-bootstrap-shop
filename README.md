# kr2-bootstrap-shop

Контрольная работа №2 по дисциплине «Фронтенд и бэкенд разработка».
Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Что сделано
- Отдельный репозиторий для КР №2 (не связан с КР №1).
- Bootstrap 5.3.3 подключён через CDN.
- Собственный файл `css/custom.css` для минимальных правок.
- Главная страница `index.html`:
  - шапка (header);
  - навигация (navbar);
  - hero-блок на сетке (`row`, `col-12 col-lg-6`);
  - блок преимуществ (`col-12 col-md-4`);
  - сетка популярных товаров (`col-12 col-md-6 col-lg-4`);
  - подвал (footer).
- Использованы:
  - 12-колоночная сетка Bootstrap;
  - `container`, `row`, `col-*`;
  - gutters `g-4`;
  - utility-классы (`my-5`, `p-4`, `text-center`, `bg-light`, `shadow-sm`, `rounded`, `h-100`).
